# Student Loan Application — Video Project

A short video that walks through how a student applies for a school loan, from asking for help with school expenses to getting the loan approved.

▶️ **[Watch the video](student-loan-application.mp4)**

## About the video

Jao, a student, needs help paying for school expenses and asks if there is a student loan. The video follows each step of the process:

1. **Find out when to apply.** The application opens one week before every periodic examination.
2. **Fill out the application form** using the application link.
3. **Know the limit.** The maximum loan is ₱3,000. Anything above that needs approval from the Controller or COO.
4. **Prepare the requirement.** One valid ID of a parent or guardian, with their signature.
5. **Submit and wait** 1 to 2 days for verification.
6. **Get the result.** Jao's application is approved.
7. **Pay on time.** The approved amount must be paid on or before the due date, within 30 days.

With the loan approved, Jao can focus on studying again.
